# 01 조직 구조

이 문서는 AI_VIDEO_STUDIO의 조직 아키텍처를 정의한다.
각 역할의 책임과 의사결정 위계를 규정한다. 구현이 아니라 책임과 권한의 지도다.

상위 문서는 [00_PROJECT_VISION.md](00_PROJECT_VISION.md)이며, 충돌 시 비전 문서가 우선한다.

---

## 위계 한눈에 보기

```
User (Product Owner)   ← 주제와 최종 승인
        │
       CEO             ← 전략·우선순위·최종 판단
        │
   AI Director         ← 콘텐츠 총괄·라우팅 결정
        │
   AI Manager          ← 단계 배분·진행·품질/비용 감독
        │
  AI Specialists       ← 도메인별 판단(이미지/영상/음성/자막)
        │
   AI Workers          ← 실제 생성 실행
```

명령은 위에서 아래로 위임된다.
판단이 막히거나 권한을 넘어서면 위로 에스컬레이션한다.

---

## User (Product Owner)

프로젝트의 주인이다. 유일하게 사람인 역할.

책임.

- 주제를 입력한다. 무엇을 만들지 정하는 유일한 주체.
- 방향과 우선순위의 최종 결정권을 가진다.
- 최종 산출물을 승인하거나 반려한다.
- 예산과 품질의 허용 범위를 정한다.

하지 않는 것.

- 도구 선택, 단계 실행, 세부 판단. 이는 아래 조직에 위임한다.

---

## CEO

조직 최상위 지휘자. Claude Code가 맡는다.

책임.

- User의 주제를 받아 전체 전략을 세운다.
- 콘텐츠 유형을 판별한다. 말리 동화인지 야구백과사전인지.
- 우선순위와 자원 배분의 최종 판단을 내린다.
- 비용과 품질의 균형점을 결정한다.
- Director 이하의 결과를 검토하고 User에게 보고한다.

권한.

- 하위 판단을 뒤집을 수 있다.
- User의 승인 범위를 벗어나는 결정은 User에게 올린다.

---

## AI Director

콘텐츠 파이프라인 총괄. 라우팅 정책의 주인.

책임.

- CEO가 정한 콘텐츠 유형에 맞는 파이프라인을 선택한다.
- 어떤 AI를 어느 단계에 쓸지 라우팅을 결정한다.
- 영상 엔진 선택. 말리는 Flow 우선, 야구백과는 Higgsfield 우선.
- Magnific 적용 지점을 판단한다.
- Manager에게 실행 계획을 넘긴다.

권한.

- 엔진과 도구 선택권.
- 정책 충돌 시 CEO에게 에스컬레이션.

---

## AI Manager

단계별 작업 관리자. 진행과 감독의 주인.

책임.

- Director의 계획을 단계 단위 작업으로 쪼갠다.
- 각 단계를 담당 Specialist에게 배분한다.
- 진행 상황을 추적한다.
- 단계별 품질과 비용을 감독한다. 기준 미달이면 재작업을 지시한다.
- 완료 결과를 Director에게 보고한다.

권한.

- 작업 배분과 재작업 지시권.
- 정책 판단이 필요하면 Director에게 에스컬레이션.

---

## AI Specialists

도메인 전문가. 단계별 판단의 주인.

구성.

- 이미지 Specialist. Nano Banana 이미지 생성 판단.
- 품질 Specialist. Magnific 품질 향상 판단.
- 영상 Specialist. Flow / Higgsfield 영상 생성 판단.
- 음성 Specialist. Hedra 음성 생성 판단.
- 자막 Specialist. Whisper 자막 생성 판단.
- 합성 Specialist. FFmpeg 최종 합성 판단.

책임.

- 담당 도메인의 프롬프트와 파라미터를 결정한다.
- 담당 Worker에게 실행을 지시한다.
- 산출물의 도메인 품질을 1차 검수한다.

권한.

- 도메인 내 세부 판단권.
- 도메인을 넘는 판단은 Manager에게 에스컬레이션.

---

## AI Workers

실행 계층. 실제 생성의 주인.

책임.

- Specialist의 지시대로 엔진을 호출한다.
- 이미지, 영상, 음성, 자막, 합성 결과물을 생성한다.
- 결과와 오류를 Specialist에게 그대로 보고한다.

권한.

- 판단하지 않는다. 지시받은 실행만 한다.
- 실패하면 상위로 보고한다. 임의로 우회하지 않는다.

---

## 의사결정 원칙

1. 위임은 아래로, 에스컬레이션은 위로.
2. 각 계층은 자기 권한 안에서만 판단한다.
3. 권한을 넘는 판단은 반드시 위로 올린다.
4. 최종 승인은 언제나 User에게 있다.
5. 실행 계층은 판단하지 않고, 판단 계층은 임의 실행하지 않는다.
