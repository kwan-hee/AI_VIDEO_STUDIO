# 00 AIOS 청사진

**AIOS = AI Operating System for Autonomous Content Creation.**
자율 콘텐츠 제작을 위한 AI 운영체제.

이 문서는 AIOS의 상위 청사진이다. 구현이 아니라 구조와 원칙의 지도다.
상위 문서는 [00_PROJECT_VISION.md](00_PROJECT_VISION.md)이며, 충돌 시 비전 문서가 우선한다.

---

## 1. AIOS란 무엇인가

AIOS는 콘텐츠를 자율로 제작하는 AI 운영체제다.

일반 OS가 하드웨어 위에서 프로그램을 조율하듯,
AIOS는 여러 AI 서비스 위에서 제작 과정을 조율한다.

- 사람은 주제만 입력한다.
- AIOS가 판단, 배분, 실행, 저장을 스스로 처리한다.
- Claude Code가 커널이자 지휘자 역할을 한다.

AIOS는 하나의 도구가 아니라, 도구들을 부리는 층이다.

---

## 2. AIOS는 왜 존재하는가

반복 노동을 제거하고 창작 의도만 남기기 위해서다.

- 영상 제작은 기획, 이미지, 영상, 음성, 자막, 합성으로 이어지는 긴 사슬이다.
- 사람이 매 단계를 손으로 잇는 것은 느리고 비싸다.
- AIOS는 이 사슬을 하나의 자동 흐름으로 묶는다.
- 사람은 방향과 승인에만 집중한다.

목표는 주제 한 줄이 완성 영상으로 바뀌는 것이다.

---

## 3. AIOS와 AI_VIDEO_STUDIO의 관계

AI_VIDEO_STUDIO는 AIOS를 짓고 검증하는 R&D 공간이다.

- AIOS는 개념이자 목표 아키텍처다.
- AI_VIDEO_STUDIO는 그 아키텍처를 실험하는 실제 프로젝트다.
- 이 안에서 검증된 기능만 나중에 운영 프로젝트로 이전한다.
- AIOS의 모든 실험은 AI_VIDEO_STUDIO 경계 안에서만 진행한다.

즉 AIOS는 무엇을 만들지, AI_VIDEO_STUDIO는 어디서 만들지에 해당한다.

---

## 4. 핵심 모듈

AIOS는 여섯 개의 핵심 모듈로 구성된다.

### AI Director

- 콘텐츠 유형을 판별하고 파이프라인을 총괄한다.
- 어떤 AI를 어느 단계에 쓸지 지휘한다.
- 조직 위계의 지휘 계층. 자세한 책임은 [01_ORGANIZATION.md](01_ORGANIZATION.md) 참조.

### Memory System

- 프로젝트의 장기 기억. 캐릭터 설정, 용어, 완료 기록을 보관한다.
- 매 작업이 과거 맥락을 잃지 않게 한다.
- `memory/` 폴더와 Obsidian이 이 층을 이룬다.

### Router

- 입력 주제를 받아 어떤 엔진으로 보낼지 결정한다.
- 콘텐츠별, 단계별 라우팅 정책을 실행한다.
- 비용과 품질을 함께 저울에 올린다.

### Engines

- 실제 생성을 수행하는 도구 계층.
- Nano Banana, Magnific, Google Flow, Higgsfield, Hedra, Whisper, FFmpeg.
- Router의 지시를 받아 결과물을 만든다.

### Workflow

- 단계들을 순서대로 잇는 실행 흐름.
- 이미지 → 영상 → 음성 → 자막 → 합성의 사슬을 관리한다.
- 이 단계에서는 정의만, 구현은 하지 않는다.

### Output Manager

- 최종 산출물의 저장, 명명, 아카이브를 담당한다.
- 결과를 정해진 위치에 정해진 규칙으로 남긴다.

---

## 5. Obsidian의 역할 — 장기 기억

Obsidian은 AIOS의 장기 기억 저장소다.

- 세션이 끝나도 사라지지 않는 지식을 보관한다.
- 캐릭터 설정, 용어 사전, 완료 프로젝트, 판단 근거를 축적한다.
- 다음 세션이 과거를 다시 유추하지 않고 이어받게 한다.
- 단기 실행 상태는 프로젝트 폴더가, 장기 지식은 Obsidian이 맡는다.

---

## 6. 인간의 역할 — 최종 결정자

사람은 유일한 최종 결정자다.

- 주제를 정하는 유일한 주체.
- 방향과 우선순위의 최종 결정권.
- 산출물을 승인하거나 반려하는 권한.
- 예산과 품질의 허용 범위 설정.

AIOS는 실행을 돕지, 주제를 정하지 않는다.

---

## 7. 규칙 — 기존 PROJECT 폴더 불가침

기존 운영 PROJECT 폴더는 절대 수정하지 않는다.

- 읽지도, 바꾸지도, 옮기지도 않는다.
- 모든 실험은 AI_VIDEO_STUDIO 안에서만 진행한다.
- 검증된 기능만 별도 이전 절차로 운영에 반영한다.

이 규칙은 예외가 없다.

---

## 8. 규칙 — 이 단계에서는 구현 없음

지금은 청사진 단계다. 구현은 하지 않는다.

- 코드 없음.
- 워크플로 없음.
- 스크립트 없음.
- 문서로 구조와 원칙만 정의한다.

구현은 이후 단계에서 검증과 함께 진행한다.
