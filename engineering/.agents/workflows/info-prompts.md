# /info-prompts

INFO 는 새 장면을 만드는 것이 아니다. **CLEAN 한 장에 그래픽만 더하는 편집**이다.

원본의 장면, 핵심 대상, 구도, 카메라 각도, 원근, 배치, 조명, 색감을 그대로 유지한다.
확대하거나 자르거나 각도를 바꾸지 않는다.

CLEAN 한 장당 INFO 한 장이다. 일대일 대응을 반드시 지킨다.
여러 장을 합치거나 콜라주로 만들지 않는다.

그래픽은 크고 선명하게 만든다. 작거나 은은하게 하지 않는다.
화살표, 링, 경계선, 호출선, 측정선은 화면에서 즉시 눈에 들어올 정도로 굵게 한다.

색 규칙을 지킨다.
heat 주황빨강(열·더운 공기) / cold 시안(찬 공기·물) / struct 청백(구조·치수) /
gold 핵심 수치 / red X, green 체크(판정). 한 이미지에 강조색 두세 가지 이상.

우선 시각화할 것: 하중 전달 방향, 부재 간 연결, 유체와 열의 흐름,
단면과 절개, 치수와 축척, 전후 비교, 공정 순서.

그래픽은 평면 장식이 아니라 3차원 공간에 존재하는 것처럼 배치한다.
호출선은 정확한 대상을 가리키고, 핵심 구조를 가리지 않는다.
이미지 안 문구는 한국어로 쓴다.

생성 시 CLEAN 의 job id 를 `image_references` 로 넘긴다.

**여기서 멈춘다.** 승인 뒤에 생성한다.
