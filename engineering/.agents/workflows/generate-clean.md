# /generate-clean

**크레딧을 차감한다.** 실행 전에 확인한다.

1. `balance` 로 잔액을 확인한다.
2. 예상 차감액(장수 x 2크레딧)을 보고하고 승인을 받았는가.

승인이 확인되면 `nano_banana_pro`, 2k, 9:16 으로 `generate_image_batch` 에 넘긴다.
한 번에 12건까지다. `jobs_wait` 로 기다린 뒤 `show_generation_by_ids` 로 한 번에 보여 준다.

생성 후 반드시 **눈으로 검수한다.** 파일명만 보고 완료로 판단하지 않는다.

- 구조가 물리적으로 말이 되는가
- 텍스트나 화살표가 섞여 들어오지 않았는가
- 세로 구도가 돌아가지 않았는가
- 라벨이 들어갈 여백이 있는가

결함이 한 장에만 있으면 그 장만 다시 만든다. 전체를 다시 만들지 않는다.
job id 를 `manifests/jobs.json` 에 기록한다. INFO 단계에서 참조로 쓴다.
