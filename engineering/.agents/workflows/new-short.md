# /new-short

인자: 주제. 없으면 주제 하나만 묻는다.

1. `<주제>_쇼츠/` 폴더와 하위 구조(script, clean, info, video, edit, manifests, prompts)를 만든다.
2. 주제를 공학 관점에서 깊게 판다. 불확실한 수치는 검색으로 확인한다.
3. AGENTS.md 의 대본 논리 네 가지를 먼저 확정한다.
   중심 질문 / 핵심 메커니즘 / 보이는 물리 흐름 / 차별점
4. 60초 분량 대본을 `script/APPROVED_NARRATION_KR.md` 에 쓴다.
   숫자는 한글로 풀어 쓴다. 근거는 `script/SOURCE.md` 에 남긴다.
5. `manifests/PROJECT_STATUS.md` 를 만들고 현재 단계를 기록한다.

**여기서 멈춘다.** 대본 승인 전에는 장면 설계도 이미지 생성도 하지 않는다.
