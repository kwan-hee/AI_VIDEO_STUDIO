# /scene-map

대본이 승인된 뒤에만 실행한다.

1. edge-tts 선희로 나레이션을 먼저 생성하고 **실제 길이를 잰다.**
   장면 수는 추측이 아니라 이 길이에서 나온다.
2. 문장을 장면으로 묶는다. 4초 클립 기준이므로 60초면 대략 15장면이다.
3. 식별자를 부여한다. 장면 `S01A`, 키프레임 `KF-01A`, 클립 `CLIP01`.
4. `manifests/IMAGE_SEQUENCE.md` 에 장면별로 적는다.
   - 이 장면이 설명하는 한 가지
   - 대응하는 나레이션 문장
   - 보여야 할 물리 흐름
   - 클립 길이
5. 한 장면은 한 가지만 설명한다. 설명할 것이 둘이면 더 중요한 하나를 고른다.
6. 예상 총비용을 산출해 보고한다.
   CLEAN 장수 x 2 + INFO 장수 x 2 + (총 초수 x 1.25)

**여기서 멈춘다.** 장면 지도 승인 전에 프롬프트를 쓰지 않는다.
