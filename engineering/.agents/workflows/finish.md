## 0. 편집 자산을 먼저 복사한다

이 단계에 처음 도달했을 때만 한다. 이미 있으면 건너뛴다.

| 가져올 것 | 원본 위치 |
|---|---|
| 쇼츠 편집 스크립트 | `C:\공학 영상만들기\청동검_쇼츠\edit\` (폴더 통째로) |
| 미드폼 편집 스크립트 | `C:\공학 영상만들기\석빙고(미드)\edit\` |
| 마무리 장면 | `C:\공학 영상만들기\outro\add_outro.py` |
| 배경 음악 | `C:\공학 영상만들기\BGM\` |

**복사만 한다.** 원본을 고치거나 원본 위치에 결과를 쓰지 않는다.
경로가 절대 경로로 박혀 있으면 복사본에서 이 작업 공간 기준으로 고친다.

## 1. 편집

2. `edit/assemble.py` 로 조립한다.
   나레이션 세그먼트 길이에 맞춰 장면 길이를 계산한다.
   클립은 짧게 자르지 않고 필요할 때만 느리게 늘린다. 감속 배율은 0.8 이상 유지한다.
   문장 수와 장면 수가 다르면 `GROUPS=[(세그먼트 목록, 클립 번호)]` 로 묶는다.
3. 정지 이미지 줌은 `kenburns.py` 를 쓴다. ffmpeg zoompan 은 쓰지 않는다.
4. 자막을 굽는다. Malgun Gothic Bold, MarginV 쇼츠 45 / 미드폼 15.
5. BGM 을 고른다. 고대·역사·자연물 소재 > 긴장·반전 구조 > 메인 순.
   음량 쇼츠 -6dB, 미드폼 -3dB. 사이드체인 덕킹, 끝 2.5초 페이드아웃.
6. `add_outro.py` 로 마무리 장면을 붙인다.
   **업로드 파일은 항상 `final_*_sub_outro.mp4`**
7. `script/TITLE_DESCRIPTION.md` 를 쓴다.
   제목안 2~3개, 설명(타임스탬프는 실제 장면 시작 시각), 핵심 요약,
   참고 출처, 태그(쉼표 구분), 썸네일 문구.
8. `manifests/PROJECT_STATUS.md` 를 갱신하고
   이번에 새로 알게 된 것을 "이번에 확인한 것" 에 적는다.
