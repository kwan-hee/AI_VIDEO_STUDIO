# 공학 쇼츠 작업 공간 — 설계의 이유

유튜브 채널 「설계의 이유」(@설계의이유)의 공학 설명 쇼츠를 만드는 폴더다.

## 여는 법

이 폴더를 Antigravity 작업 공간으로 연다.
`AGENTS.md` 가 자동으로 읽히므로 규칙을 따로 붙여 넣지 않아도 된다.

`PROMPT_KICKOFF.md` 에서 상황에 맞는 프롬프트를 복사해 붙인다.

## 무엇이 어디에 있나

| 파일 | 내용 |
|---|---|
| `AGENTS.md` | 상시 적용되는 제작 규칙. 엔진, 단가, 프롬프트 규칙, 승인 게이트 |
| `PROMPT_KICKOFF.md` | 새 프로젝트와 이어 하기 착수 프롬프트, 예상 비용표 |
| `.agents/workflows/` | 단계별 슬래시 명령어 8개 |
| `run/estimate.py` | 장면 목록의 비용과 중복을 계산한다. 크레딧을 쓰지 않는다 |
| `run/compose.py` | 완성된 클립을 한 편으로 합친다 |

## 제작 사슬

```
SCRIPT → CLEAN → INFO → VIDEO → EDIT
```

앞 단계가 승인되지 않으면 다음으로 넘어가지 않는다.

## 기존 체계와 달라진 점

영상 엔진을 `wan3_0` 에서 **`kling3_0` (sound=off)** 로 바꾼다.
같은 길이에서 28.6% 싸다. 4초 클립 기준 5.00 대 7.00 이다.

`sound` 기본값이 `on` 이고 켜면 초당 1.75 로 올라 Wan 과 같아지므로,
페이로드에 `"sound": "off"` 를 반드시 명시해야 절감이 성립한다.

나머지 규칙(폴더 구조, 식별자, 승인 게이트, TTS, 인포그래픽 스타일,
BGM, 마무리 장면, 업로드 파일명)은 기존 CODEX 체계와 CLAUDE.md 를 그대로 따른다.
