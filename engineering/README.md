# 공학 영상 만들기 (Kling 3.0)

유튜브 채널 「설계의 이유」(@설계의이유)의 공학 설명 쇼츠를
**Kling 3.0 단일 엔진으로** 만드는 작업 폴더다.

## 기존 폴더와의 관계

| 폴더 | 엔진 | 상태 |
|---|---|---|
| `C:\공학 영상만들기\` | `wan3_0` | **읽기 전용. 손대지 않는다** |
| `C:\공학 영상 만들기 (kling 3.0)\` | `kling3_0` | 이 폴더. 여기서만 작업한다 |

기존 폴더는 검증된 작업장이므로 그대로 둔다.
필요한 스크립트나 BGM 은 **복사해서** 쓰고 원본은 건드리지 않는다.
산출물은 전부 이 폴더 안에만 쓴다.

## 여는 법

이 폴더를 Antigravity 작업 공간으로 연다.
`AGENTS.md` 가 자동으로 읽히므로 규칙을 따로 붙여 넣지 않아도 된다.

`PROMPT_KICKOFF.md` 에서 상황에 맞는 프롬프트를 복사해 붙인다.

## 작업 흐름

```
공학 쇼츠 기획실에서 기획서 .md 뽑기
  → 이 폴더에 [주제]_쇼츠 폴더 만들기
  → 그 안에 기획서 .md 넣기
  → Antigravity 로 이 폴더 열고 프롬프트 붙여넣기
```

기획서가 있으면 대본을 새로 쓰지 않고 그것으로 만든다.
**내레이션 한 줄이 한 장면이다.** 줄 수가 곧 장면 수다.

## 파일 안내

| 파일 | 내용 |
|---|---|
| `AGENTS.md` | 상시 규칙. 엔진, 단가, 프롬프트 규칙, 승인 게이트 |
| `PROMPT_KICKOFF.md` | 착수 프롬프트와 예상 비용표 |
| `.agents/workflows/` | 단계별 슬래시 명령어 |
| `run/estimate.py` | 비용과 중복을 미리 계산한다. 크레딧을 쓰지 않는다 |
| `run/compose.py` | 완성된 클립을 한 편으로 합친다 |

## 기존 체계와 다른 점

영상 엔진 하나뿐이다. `wan3_0` → `kling3_0` (`sound: "off"`).
4초 클립 기준 7.00 → 5.00 으로 28.6% 싸다.

`sound` 기본값이 `on` 이고 켜면 초당 1.75 로 올라 Wan 과 같아지므로,
페이로드에 `"sound": "off"` 를 반드시 명시해야 절감이 성립한다.

나머지 규칙(폴더 구조, 식별자, 승인 게이트, 선희 TTS, 인포그래픽 스타일,
BGM, 마무리 장면, 업로드 파일명)은 기존 체계를 그대로 따른다.
