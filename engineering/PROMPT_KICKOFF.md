# Antigravity 착수 프롬프트

이 폴더를 Antigravity 작업 공간으로 열면 `AGENTS.md` 는 자동으로 읽힌다.
아래 프롬프트는 그 위에서 **이번 작업이 무엇인지**만 지정한다.

---

## 1. 새 쇼츠를 시작할 때

```text
이 작업 공간의 AGENTS.md 를 처음부터 끝까지 읽고 이번 프로젝트의 운영 명세로 삼아라.

주제: [주제를 여기에]
목표 길이: 60초
채널: 설계의 이유 (@설계의이유) — 세로 9:16 공학 설명 쇼츠
시각화할 핵심 물리 현상: [공기 / 물 / 흙 / 열 / 압력 / 하중 / 진동 / 에너지 중 하나]
영상 엔진: Kling 3.0, sound=off, 클립당 4초
이미지 엔진: nano_banana_pro 2k

새 프로젝트다.

먼저 이 주제를 공학 관점에서 깊게 파고 대본만 써라.
대본에 들어가는 수치는 검색으로 확인한 뒤 쓰고, 근거를 script/SOURCE.md 에 남겨라.

내가 대본을 승인하기 전에는 장면 설계도, 이미지 생성도 하지 마라.

완료한 단계마다 프로젝트 폴더 안에 MD 파일로 저장하고,
같은 내용을 대화창에도 복사 가능한 코드 블록으로 보여 줘라.

크레딧이 드는 단계에 들어가기 전에는 예상 차감액과 현재 잔액을 먼저 보고하고
내 승인을 받아라. 설정에 대한 내 답변은 승인이 아니다.
```

---

## 2. 하던 작업을 이어서 할 때

```text
이 작업 공간의 AGENTS.md 를 처음부터 끝까지 읽고 이번 프로젝트의 운영 명세로 삼아라.

프로젝트 폴더: [경로]
현재 단계: [예: CLEAN 이미지 생성 완료]

기존 자산과 문서를 먼저 살펴라.
manifests/PROJECT_STATUS.md 와 실제 폴더를 함께 확인하고,
파일명만 보고 완료로 판단하지 마라.

완료된 단계는 다시 만들지 마라.
다음에 해야 할 단계 하나만 수행하고 멈춰라.
```

---

## 3. 단계별 클릭 실행

슬래시 명령어로 각 단계를 부른다.

| 명령어 | 단계 | 크레딧 |
|---|---|---|
| `/new-short` | 폴더 생성, 조사, 대본 | 없음 |
| `/scene-map` | 나레이션 길이 측정, 장면 지도, 비용 산출 | 없음 |
| `/clean-prompts` | CLEAN 프롬프트 작성 | 없음 |
| `/generate-clean` | CLEAN 실제 생성 | **차감** |
| `/info-prompts` | INFO 편집 프롬프트 작성 | 없음 |
| `/video-prompts` | CLEAN→INFO 4초 영상 프롬프트 작성 | 없음 |
| `/generate-video` | Kling 3.0 제출 | **차감** |
| `/finish` | 조립, 자막, BGM, 마무리 장면, 공개 문안 | 없음 |

---

## 4. 프로젝트 한 편의 예상 비용

60초 쇼츠, 4초 클립 15개 기준이다.

| 항목 | 수량 | 단가 | 소계 |
|---|---:|---:|---:|
| CLEAN 이미지 | 15장 | 2 | 30 |
| INFO 이미지 | 15장 | 2 | 30 |
| 영상 클립 (Kling 3.0, sound=off) | 15개 x 4초 | 5.00 | 75 |
| 나레이션 (edge-tts 선희) | — | 무료 | 0 |
| **합계** | | | **135** |

같은 구성을 Wan 3.0 으로 만들면 165 크레딧이다. **편당 30 크레딧이 차이 난다.**

---

## 5. 엔진을 바꾸는 것이므로 첫 편은 이렇게

기존 체계는 `wan3_0` 을 썼다. Kling 3.0 으로 옮기는 첫 편에서는
전체를 바꾸기 전에 **한 장면으로 먼저 비교하라.**

```text
CLIP01 한 장면만 Kling 3.0 과 Wan 3.0 으로 각각 생성해서 나란히 비교해 줘.
같은 CLEAN, 같은 INFO, 같은 프롬프트, 4초로 맞춰라.
비교 기준은 세 가지다.

1. 끝 프레임이 INFO 와 얼마나 정확히 일치하는가
2. 그래픽이 동시에 뜨지 않고 순서대로 지어지는가
3. 한국어 라벨이 깨지지 않는가

차감은 Kling 5.00 + Wan 7.00 = 12.00 크레딧이다. 진행할지 물어봐라.
```

세 기준을 모두 통과하면 나머지 14클립을 Kling 으로 진행한다.
통과하지 못하는 항목이 있으면 그 항목을 보고하고 판단을 나에게 맡긴다.
